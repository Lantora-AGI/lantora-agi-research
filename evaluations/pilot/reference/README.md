# Stage 2 maintainer reference bundle

This directory contains a machine-comparable reference for the deterministic
Stage 2 pilot run defined in Issue #15.

## Evidence status

This reference was generated by the original maintainer on 2026-09-08, after
an independent contributor reported that the repository lacked the artifacts
needed for strict equivalence testing. It is therefore a **retroactively
published maintainer reference**, not preregistered or independent evidence.
The contributor's earlier partial-reproduction result must remain part of the
record regardless of the comparison outcome.

The reference was generated from an unmodified export of commit
`8adf28a42715f0e4de51e75e8cd943269de32e1b` using Python 3.12.14 on macOS
26.6.2 arm64. Generation and evaluation produced 450 valid tasks, 450/450
heuristic successes, 85/450 seeded-random successes, and 18 passing tests.

## Contents and equivalence

`pilot-reference-8adf28a.json` retains:

- all 450 canonical task hashes;
- adapter identity, configuration, seed, exclusions, and retries;
- all 900 task identifiers, output hashes, statuses, outcomes, scores, errors,
  and step counts;
- grouped statistics and transfer differences.

It intentionally excludes timestamps, measured durations, platform strings,
environment inventories, and hashes of files containing those fields. Those
values may vary under the equivalence criterion in the validation protocol.

## Compare another run

From the repository root, substitute paths to the reproducer's artifacts:

```bash
python3.12 scripts/pilot_reference.py compare \
  --reference evaluations/pilot/reference/pilot-reference-8adf28a.json \
  --generation-manifest runs/replication-suite/generation-manifest.json \
  --heuristic-manifest runs/replication-heuristic/manifest.json \
  --heuristic-results runs/replication-heuristic/results.json \
  --random-manifest runs/replication-random/manifest.json \
  --random-results runs/replication-random/results.json
```

The command exits with status 0 only when every retained canonical field
matches. It reports up to 100 field-level differences otherwise.
